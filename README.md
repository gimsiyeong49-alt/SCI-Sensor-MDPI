# SCI-Sensor-MDPI

사족보행 로봇(Unitree Go2, Hesai XT16 라이다, RealSense RGB-D, 팬틸트 카메라)이 몇 층인지 모르는 상태에서 안내도 위 자기 위치를 찾고, 위치가 애매할 때만 멈춰 호실 번호판을 보게 하는 연구의 코드와 실험 정리다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `floor_id/` | 위치추정 패키지. 라이다 구조점과 오돔을 층별 안내도에 맞춰 위치·방향·축척 후보와 층 순위를 낸다(`floor_id.py` 층 판별, `localizer/rt_localizer.py` 실시간 위치추정, `localizer/metric_fit_v2.py` 후보 정밀 검증, `maps/` 세 건물 지도) |
| `E2_초기위치/` | 제자리 관측 한 번으로 모든 층·칸·방향·축척 후보 중 Top-100 뽑기 |
| `E3_걸으며좁히기/` | 15·30·45·60초 걸으며 후보 좁히기 |
| `E4_표지판호출/` | 매 시점 위치 상태 판단과, 모호할 때만 표지판 앞에서 멈추기(녹화본 실험) |
| `이벤트_실시간/` | 로봇에서 도는 표지판 멈춤·팬틸트 조준 코드(2026-10-09 판) |

실험 폴더마다 `README.md` 는 파일별 역할과 실행 순서, `실험정리.md` 는 방법·결과·남은 문제다. 실험 코드는 `floor_id` 를 고치지 않고 불러 쓴다.

## 지금까지 결과

모든 실험은 같은 65개 출발점(정보관 1~9층, 공학관 1·2층, 소융대 1·6층의 13개 층 × 장소 종류 5곳)을 쓴다. 정답(층, 3 m, 30°)은 채점에만 쓰고 후보 계산이나 멈춤 판단에는 넣지 않았다.

E2 에서는 서서 한 번 본 라이다로 정답 위치가 Top-100 안에 드는 출발점이 31곳(48%)이었다. 라이다만으로 충분했고, 남은 차이는 대부분 축척이다.

E3 에서는 E2 후보를 이어받고 15초마다 위치추정 노드가 층마다 새로 찾은 후보를 합쳤다. 1위가 맞는 출발점은 15·30·45·60초에 15·21·26·22곳이고, 후보 안에 정답이 있는 곳은 42·46·49·50곳이다. 노드만 쓸 때(11·13·12·15곳)보다 크게 올랐다. 라이다 기하는 층 안 위치는 잘 찾지만 몇 층인지는 잘 가르지 못한다.

E4 의 위치 상태 판단은 "그 시점 1위가 틀린 순간"을 모호해야 할 순간으로 볼 때 정밀도 76%, 재현율 99%(F1 0.86)이고, 틀렸는데 확정이라고 한 경우는 0.6% 다. 멈춘 곳 중 진짜 표지판은 절반쯤(50%)이고, 장소별로는 복도 70%, 막다른 곳 30% 로 갈린다. 60초 안에 진짜 번호판 앞에 선 출발점은 43곳이고, 그 번호로 층을 정하면 60초 뒤 위치가 맞는 곳이 23곳에서 39곳으로 는다(처음부터 층을 알면 46곳).

## 남은 문제

정답 후보가 벽 관통 판정에 걸려 빠지는 곳 중 세 곳(정보관 3층 출발점4, 9층 출발점5, 1층 출발점5)은 지도에서 계단 입구와 계단 칸이 막힌 벽으로 처리돼 생긴다. 소융대 지도는 2026-10-05 에 새로 만들어졌는데, 소융대 출발점 10곳의 결과는 그 전 지도로 돌린 것이다. 표지판 정밀도는 멈춤 규칙이 아니라 RealSense 640×480 화면의 검출기가 정한다.

다음은 로봇 실시간 쪽이다. 로봇에 들어간 위치추정·지도·이벤트 판을 확인하고, 실시간 위치추정 기록을 이벤트 실행기(`--loc-url`)에 붙여 멈춤 → 조준 → 촬영 → 번호 판독을 현장에서 시험한다.

## 돌리려면

층별 데이터셋(A1.3.1 구조점·오돔·RGB-D 녹화, 채점용 정답)은 용량 때문에 넣지 않았다. 코드에 적힌 데이터 경로(`/data…`, `/data2…`)는 각자 환경에 맞게 바꿔야 하고, 실험 코드는 위치추정 패키지를 `/data/kci_work/floor_id_pkg/floor_id` 경로로 부른다.

파이썬 3.10 에서 numpy, scipy, opencv, matplotlib 으로 돌렸다. 이미지 모델(SigLIP base-patch16-224, Qwen3-VL-2B-Instruct)은 torch·transformers 가 든 별도 환경에서 불렀다. 위치추정은 CuPy 가 있으면 GPU 로 도는데 결과는 CPU 와 같다. 결과 그림과 표 전체는 따로 전달한 정리본(zip)에 있다.
