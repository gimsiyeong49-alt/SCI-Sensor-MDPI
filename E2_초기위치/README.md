# 코드: E2 초기위치

이 실험에 쓴 스크립트를 실제 import 관계를 따라 모았다. 원래 작업 폴더의 `scripts/` 에서 그대로 복사했고, 공유용이라 사람 이름이 든 이름만 내용 이름으로 바꿨다(예: 위치추정 1초 기록 스크립트는 `loc_topk_series.py`, 협업자 위치추정 패키지 경로는 `floor_id_pkg`).

위치추정 패키지는 저장소의 `floor_id/` 다(코드에서는 `/data/kci_work/floor_id_pkg/floor_id` 로 부른다). 그대로 돌리려면 두 가지가 더 필요하다. 층별 데이터셋(A1.3.1 구조점·오돔·RGB-D 녹화, 채점용 정답)과, 코드에 적힌 데이터 경로(`/data…`)를 각자 위치로 바꾸는 것이다. 모델(SigLIP, Qwen-VL)은 `/data2/vlm_env` 파이썬 환경에서 불렀다.
